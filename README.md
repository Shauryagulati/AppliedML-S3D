# 17634 - Applied Machine Learning


## Course Description
Automated decisions systems increasingly rely on machine learning models for classification, regression, and
prediction. The practical application of machine learning requires understanding the basic structure,
assumptions, and limitations for a variety of model forms; how to formulate a meaningful problem; how to
acquire and understand relevant data; how to select, train, evaluate, and use machine learning models; and
how to securely integrate these models into deployable pipelines. This course introduces these concepts for the
most widely used supervised and unsupervised machine learning methods, and the course includes a mix of
classroom experience, a hands-on coding project using a real dataset of the student’s choosing, and
communication of the problem and results through a class presentation.


## Learning Objectives
• Problem Formulation: choosing the right question, business value, data sources
• Mathematics of Data Science (conceptual): statistical learning, optimization, algorithms
• Machine Learning Models: supervised, semi-supervised, unsupervised; classification and prediction; linear models, tree-based models, neighbor-based models, support vector machine, neural networks.
• Exploratory Data Analysis: computing statistics, data visualization, feature engineering, feature selection
• Modeling Process: training, validating, testing, evaluation metrics, tuning, feature importance, explainability
• MLOPS: deployment, versioning, operations, monitoring and maintenance, security
• Tools: Python, R, scikit-learn, Google Colab, Jupyter, Visual Studio Code
